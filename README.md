# Executive Compensation Analysis

Analysis of executive compensation data to identify trends, benchmarks, and insights across companies and industries.

## Overview

This project explores executive pay structures — including base salary, bonuses, equity grants, and total compensation — to surface patterns related to company size, sector, performance, and other factors.

## Project Structure

```
executive-compensation-analysis/
├── data/
│   ├── raw/          # Source data (gitignored)
│   ├── interim/      # Intermediate cleaned data (gitignored)
│   └── processed/    # Final datasets (gitignored)
├── notebooks/        # Exploratory analysis (Jupyter)
├── src/              # Source code / scripts
├── output/           # Charts, tables, reports
└── README.md
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kipp-andrew-p/executive-compensation-analysis.git
   cd executive-compensation-analysis
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
